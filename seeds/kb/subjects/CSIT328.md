# CSIT328 — Web Security

- **Credit Points:** 6
- **Co-Requisite:** 12 credit points at 200 level
- **Pre-Requisite:** (CSIT110 or CSIT111) and CSIT128
- **Availability:**
  - Singapore Institute of Management: SIM S2
  - Wollongong: Autumn
- **Handbook URL:** https://courses.uow.edu.au/subjects/2026/CSIT328

The web, also known as World Wide Web (WWW), is now one of the essential Internet services. However, as web services become versatile, the number of web vulnerabilities has increased dramatically. In this subject, students will gain insight into the latest web threats. They will also learn the fundamentals of web security and understand the technical aspects of web defence.
