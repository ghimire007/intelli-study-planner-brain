# CSCI471 — Modern Cryptography

- **Credit Points:** 6
- **Subject Level:** 400-level
- **Prerequisites:** 24cp @300 level
- **Corequisites:** none
- **Exclusions:** none
- **Degree Restrictions:** none
- **Tags / Topic Areas:** none
- **Availability:**
  - Wollongong: Spring
- **Handbook URL:** https://courses.uow.edu.au/subjects/2026/CSCI471

This subject provides a review of modern cryptography. Topics include one-way function, pseudorandom generator, pseudorandom function, block cipher, stream cipher, message authentication code, hash function, public key encryption, digital signatures, identity-based cryptography and advanced cryptographic topics such as post-quantum cryptography.
