# ECTE364 — Data Communications

- **Credit Points:** 6
- **Subject Level:** 300-level
- **Prerequisites:** ENGG100 OR CSIT127 OR (ECTE233 and MATH141)
- **Corequisites:** none
- **Exclusions:** none
- **Degree Restrictions:** none
- **Tags / Topic Areas:** none
- **Availability:**
  - Dubai: DXB UG Autumn
  - UOW Malaysia Penang: UOWM Tri 1, UOWM Tri 2, UOWM Tri 3
  - Wollongong: Spring
- **Handbook URL:** https://courses.uow.edu.au/subjects/2026/ECTE364

Topics covered in this subject include: basics of data communications and fundamentals of computer networks; layered protocols; error correction techniques; network types and topologies; local area networks; wide area networks; packet switching; internet and transport protocols; and internet applications.
