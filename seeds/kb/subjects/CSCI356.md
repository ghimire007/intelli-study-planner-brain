# CSCI356 — Game Engine Essentials

- **Credit Points:** 6
- **Co-Requisite:** CSIT214
- **Pre-Requisite:** CSIT121
- **Availability:**
  - Dubai: DXB UG Winter
  - Singapore Institute of Management: SIM S4
  - Wollongong: Spring
- **Handbook URL:** https://courses.uow.edu.au/subjects/2026/CSCI356

This subject will introduce fundamental concepts and techniques required in the development of games and game engines. Game engine components that will be examined include rendering, collision and physics, artificial intelligence among others. The design and development of these components will be illustrated using appropriate software and application programming interfaces. Among others, topics covered in this subject will include game loops and time management, handling input, cameras, particles, collision detection, rigid-body dynamics, terrain, path-finding, and state machines.
