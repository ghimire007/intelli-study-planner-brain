# CSCI426 — Software Testing and Analysis

- **Credit Points:** 6
- **Subject Level:** 400-level
- **Prerequisites:** 24 cp @ 300 level
- **Corequisites:** none
- **Exclusions:** none
- **Degree Restrictions:** none
- **Tags / Topic Areas:** General Schedule
- **Availability:**
  - Wollongong: Autumn
- **Handbook URL:** https://courses.uow.edu.au/subjects/2026/CSCI426

Testing is a crucial task in the software development life cycle, and can easily exceed fifty percent of a project's total development cost. This subject will provide students with practical software testing and analysis methods for software quality assurance. Topics include: software qualities, static analysis methods including reviews and analysis by tools, specification-based or black-box testing techniques, structure-based or white-box testing techniques, debugging techniques, data flow analysis, model checking, automation of testing, quality assurance for Web applications, testing for software security, testing throughout the software life cycle, test management, and the psychology of testing. Practical components will include designing and implementing strategies and methods to test real-world programs effectively and efficiently.
