# CSIT470 — Security Essentials

- **Credit Points:** 6
- **Subject Level:** 400-level
- **Prerequisites:** 18cp CSCI/CSIT 300-level subjects
- **Corequisites:** none
- **Exclusions:** none
- **Degree Restrictions:** none
- **Tags / Topic Areas:** none
- **Availability:**
  - Wollongong: Autumn
- **Handbook URL:** https://courses.uow.edu.au/subjects/2026/CSIT470

This subject provides essential knowledge of security. The subject will also introduce a wide range of modern security topics including privacy, network defence, hardware security, cyber physical system security, usability and information warfare.  Students will be able to apply the knowledge gained from this subject to address various security issues.
