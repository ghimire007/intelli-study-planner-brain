# CSIT110 — Fundamental Programming with Python

- **Credit Points:** 6
- **Availability:**
  - Dubai: DXB UG Autumn, DXB UG Winter
  - Liverpool: Autumn, Spring
  - Singapore Institute of Management: SIM S1, SIM S3
  - Wollongong: Autumn, Spring
- **Handbook URL:** https://courses.uow.edu.au/subjects/2026/CSIT110

This subject uses Python language to introduce students with fundamental programming concepts such as procedural programming, variable, data type, array, recursive function, conditional expression, selection statement, repeating instruction. This subject also develops student skills in the design and implementation of well structured algorithms to a range of mathematical problems.
