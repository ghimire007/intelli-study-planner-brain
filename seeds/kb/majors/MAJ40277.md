# MAJ40277 — Software Engineering for BCompSc

- **Credit Points:** 24
- **Handbook URL:** https://courses.uow.edu.au/aos/2026/MAJ40277

This major addresses the software engineering process using an Object Oriented approach. Students work in a group that mimics the working environment of the software development industry.

## Structure
- **Core (24 CP)**
  - CSCI318 — Software Engineering Practices & Principles (6 CP)
  - CSIT377 — Enterprise Web Development (6 CP)
  - CSCI334 — Software Design (6 CP)
  - ISIT219 — Knowledge and Information Engineering (6 CP)
